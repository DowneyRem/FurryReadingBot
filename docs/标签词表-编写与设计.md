# 标签词表：编写与设计

本文说明 `tags.toml` 的当前设计与编写方式。词表只做一件事：**把来源站点的自由写法映射成规范名，并按需要展开上级标签**。

## 1. 文件角色

- 唯一源文件：`tags.toml`（TOML）
- 每条记录一个表：`[TagName]`
- 表名即规范名，输出时原样使用；匹配时不区分大小写

## 2. 全局配置 `[meta]`

```toml
[meta]
schema = 2
match = "casefold"
parts_mode = "split"
```

| 字段 | 含义 |
|------|------|
| `schema` | 词表结构版本 |
| `match` | 匹配方式：统一 NFKC + casefold |
| `parts_mode` | 复合标签拆分策略，见下文 |

### `parts_mode`

| 值 | 行为 |
|----|------|
| `split`（默认） | 只拆成基础标签，**不**继承基础标签的上级 |
| `inherit` | 拆分后再按普通标签解析，会带上各自的上级 |

## 3. 两类标签

| 类型 | 怎么判定 | 字段 | 输出 |
|------|----------|------|------|
| 复合标签 | 有 `parts` | `parts` | 只输出拆开后的基础标签，**自己不出现** |
| 原子标签 | 无 `parts` | 可选 `parents` | 输出自己 + 上级的传递闭包 |

**不变量：** 输出集合里只有原子标签。复合标签是输入侧的拆分规则，不是输出词汇。

`parts` 与 `parents` **互斥**：同一条记录不能两者都非空。

### 复合示例

```toml
[GayFurry]
group = "orientation"
order = 240
parts = ["Gay", "Furry"]
aliases = ["ケモホモ", "ホモケモ", "兽人同性", "獸人同性"]
```

`ケモホモ` → `#Gay #Furry`（没有 `#GayFurry`）

### 原子 + 上级示例

```toml
[Transfur]
group = "plot"
order = 780
parents = ["Transformation", "Furry"]
aliases = ["兽化", "獸化", "TF"]
```

`兽化` → `#Transfur #Transformation #Furry`

```toml
[R18G]
parents = ["R18"]

[CBT]
parents = ["R18G"]
```

`CBT` → `#CBT #R18G #R18`（上级传递）

## 4. 字段说明

| 字段 | 适用 | 类型 | 说明 |
|------|------|------|------|
| 表名 | 全部 | — | 规范名；`^[A-Za-z][A-Za-z0-9_]*$`；casefold 后全局唯一 |
| `group` | 建议 | string | 分组，用于排序与展示 |
| `order` | 建议 | int | 组内排序权重，越小越靠前 |
| `parts` | 仅复合 | string[] | 拆分目标；自身不输出 |
| `parents` | 仅原子 | string[] | 上级标签；输出时取传递闭包 |
| `aliases` | 全部 | string[] | 来源写法（可含空格、中日文、缩写） |

可选但未强制的字段（若以后需要可自行加）：`status` 等。当前解析器只依赖上表字段。

## 5. 匹配规则（编写时要知道）

对任意输入字符串：

1. NFKC 归一（全角数字/字母等）
2. 去掉前导 `#` / `＃`
3. 空白折叠为单空格
4. `casefold()`（比 `lower()` 更彻底）

然后：

1. **整串**在别名索引里命中 → 对应该规范名（因此别名可以带空格，如 `Gay furry`）
2. 否则按分隔符 `[\s/,，、|;；]+` **拆开**，每一段都命中才接受
3. 否则视为残余（residual），不映射

简繁、平片假名、异体写法：**运行时不做互转**。需要覆盖的写法必须写进 `aliases`。

## 6. 编写约定

### 新增原子标签

```toml
[NewTag]
group = "act"
order = 999
aliases = ["中文写法", "繁體寫法", "English Alt"]
```

有固定上级时再加：

```toml
parents = ["SomeParent"]
```

- 上级必须是**原子**标签（不能指向带 `parts` 的复合标签）
- 上级会传递：子的子也会带出更上层

### 新增复合标签

仅当「名字就是若干基础标签的拼接、且输出里不需要保留这个名字」时使用：

```toml
[FooBar]
group = "..."
order = 999
parts = ["Foo", "Bar"]
aliases = ["foobar", "Foo Bar", "某某复合写法"]
```

校验提示：`name` 若不是 `parts` 的直接拼接，会给出警告，提醒确认该用复合还是原子+parents。

### 别名

- 同一别名（normalize 后）全局只能属于一个规范名
- 不要把规范名自己再写进 aliases
- 简体、繁体、日文、空格写法分别列出
- 空字符串别名非法

### 命名与排序

- 表名用 ASCII 标识符风格，稳定、可当 hashtag
- `group` + `order` 决定输出顺序；同 order 再按名字
- 相关标签的 order 建议留间隔，方便以后插入

## 7. 校验要点（由 `tagtool.py` 执行）

- 表名合法且 casefold 唯一
- 别名 normalize 后全局唯一、非空
- `parts` / `parents` 引用存在、不自指
- 二者不同时出现
- `parents` 不得指向复合标签
- `parts` / `parents` 无环
- `parts_mode` 只能是 `split` 或 `inherit`

有 ERROR 时不应上线；WARN 需人工确认。
