# 08 · 标签词表（`tags.toml`）

词表只做一件事：**把来源站点的自由写法映射成规范名，并按需要展开上级标签**。
日常维护只需要 `tags.toml` + `sources/tags.py`，没有别的脚本参与；
`Novel/Series/Author` 构造时自动把来源写法换成规范名，认不出的写法落盘到
`data/unknown_tags.json`，人工判断后再补 `aliases`。

> 输出约定：`aliases` 是等义写法，只输出标准名；`parts` 是交集/组合，默认不输出自身；
> `parents` 是分类上级，默认输出自己 + 父集；`print` 控制任意标签自身是否输出（省略时 `parts` 默认 false，其余默认 true）。

## 1. 文件角色

| 文件 | 运行时需要 | 作用 |
|---|---|---|
| `data/tags.toml` | **是** | 唯一词表源文件 |
| `sources/tags.py` | **是** | 加载 / 校验 / 解析 / 入口规范化的唯一实现（`Vocabulary`、`load_vocabulary`、`get_vocabulary`、`canonicalize_tags`、`display_tags`、`normalize`）；**不写盘** |
| `services/tag_service.py` | **是** | 装配留档 + 运营读写（`install_tag_archive`、`unknown_tags`、`forget_unknown_tags`、`clear_unknown_tags`） |
| `storage/unknown_tags.py` | **是** | 未识别标签的落盘表（`UnknownTagStore`：`count` 按作品数累加、首末时间、显式 `prune()`） |
| `data/unknown_tags.json` | 自动生成 | 未识别写法的留档，供人工判断后补 `aliases`；**不自动淘汰** |
| `data.example/tags.toml` | 否 | 小样例，试规则用；同时是 `test/test_tags.py` 的守门样本 |
| `test/test_tags.py` | 否 | 规则单测 + 两份词表的 `errors == []` 守门 |


## 2. 规则速览

| 类型 | 怎么判定 | 可用字段 | 输出 |
|---|---|---|---|
| 复合标签 | 有 `parts`、无 `parents` | `parts`、`print` | 默认只输出拆开后的基础标签；`print = true` 时也输出自身 |
| 分类标签 | 无 `parts`、有 `parents` | `parents`、`print` | 默认输出自己 + 上级的传递闭包；`print = false` 时只输出上级 |
| 纯原子标签 | 无 `parts`、无 `parents` | `print` | 默认输出自己；`print = false` 时不输出 |

**默认情况下输出集合里只有原子标签。** 复合标签是输入侧的拆分规则，不是默认输出词汇；只有显式 `print = true` 时组合名才会进入输出。

`parts` 与 `parents` **互斥**，且 `parts` 不能指向另一个复合标签（不支持嵌套）。

`parts` 内的标签会继续按自身规则解析：如果它有 `parents`，继续继承。

`print` 是所有标签通用的自身输出开关：

- 省略：`parts` 默认 `false`（不输出自身），其余默认 `true`
- `print = true`：强制输出自身（`parts` 节点也会输出 `#GayFurry`）
- `print = false`：隐藏自身；`parts` / `parents` 的展开照常继续

```toml
[GayFurry]                       # 复合：ケモホモ → #Gay #Furry
group = "orientation"
order = 240
parts = ["Gay", "Furry"]
aliases = ["ケモホモ", "兽人同性"]
print = true                     # 输出 #GayFurry #Gay #Furry；省略则只输出 #Gay #Furry

[Transfur]                       # 原子 + 上级：兽化 → #Furry #Transfur
group = "plot"
order = 780
parents = ["Transformation", "Furry"]
aliases = ["兽化", "TF"]

[Transformation]                 # 纯原子标签也可以隐藏自己
group = "plot"
order = 775
print = false                    # #Transformation 不输出，但其它标签仍可引用它

[AnthroDragon]                   # 分类节点：默认输出自己 + 父集
group = "species"
order = 2050
parents = ["Dragon"]
print = false                    # 只输出 Dragon → Scalie → Furry，不输出 AnthroDragon

[R18G]                           # parents 会传递：挂了 R18 时，CBT → #R18 #R18G #CBT
parents = ["R18"]                # 当前生产词表没挂，实际只出 #R18G #CBT
```

## 3. 全局配置与字段

```toml
[meta]
schema = 2
match = "casefold"
# groups = ["rating", "orientation", "species", "act", "plot"]   # 可选：显式规定输出组序
```

| 字段 | 说明 |
|---|---|
| `schema` | 词表结构版本，目前只支持 `2`；填别的直接 ERROR |
| `match` | 只支持 `"casefold"`；归一规则写死在 `sources/tags.py:normalize()`，这里只是声明 |
| `groups` | 可选。输出时的组顺序；不写就按词表里 `group` **首次出现的顺序** |

| 字段 | 适用 | 类型 | 说明 |
|---|---|---|---|
| 表名 | 全部 | — | 规范名，也是输出的 hashtag；`^[A-Za-z][A-Za-z0-9_]*$`；casefold 后全局唯一 |
| `group` | 建议 | string | 分组，决定输出顺序的第一关键字 |
| `order` | 建议 | int | 组内排序权重，越小越靠前；**必须写整数**（写字符串会 ERROR） |
| `parts` | 仅复合 | string[] | 拆分目标；自身默认不输出；`print = true` 可输出自身；不能指向复合标签 |
| `parents` | 仅分类 | string[] | 上级；输出取传递闭包；上级必须是原子标签；可配 `print` |
| `print` | 全部 | bool | 是否输出自身；省略时 `parts` 默认 `false`、其余默认 `true`。TOML 字段名是 `print`，Python 内部变量名用 `print_self` |
| `aliases` | 全部 | string[] | 来源写法（可带空格、中日文、缩写） |

**输出顺序 = `group` 序 → `order` → 名字。** `order` 是词表内的全局序号（各组数值可以交叉），
所以想让某组排在前面，改的是 `group` 的顺序（或 `meta.groups`），而不是把整组 order 重排。

## 4. 匹配规则

对任意输入字符串：① NFKC 归一（全角数字/字母）→ ② 去掉前导 `#` / `＃` → ③ 空白折叠为单空格 → ④ `casefold()`。

然后：

1. **整串**命中别名索引 → 直接返回该规范名（所以别名可以带空格，如 `Gay Furry`）；
2. 否则按分隔符 `[\s/,，、|;；]+` 拆开，**每一段都命中**才接受；
3. 否则视为残余（residual），不映射。

两条容易误解的点：

- **简繁、平片假名、异体写法运行时不做互转。** 要覆盖的写法必须写进 `aliases`。
- **不做子串匹配。** `猫耳` 不会命中 `Cat`（`猫` 才是别名），所以单字别名（`兽`、`熊`、`虎`）的风险仅限于「来源标签恰好就是这个字」，不会误伤长词。

## 5. 编写指南

新增原子标签：

```toml
[NewTag]
group = "act"
order = 999
aliases = ["中文写法", "繁體寫法", "English Alt"]
# parents = ["SomeParent"]    # 有固定上级时才写
```

新增复合标签（仅当「名字就是若干基础标签的拼接、且输出里不需要保留这个名字」）：

```toml
[FooBar]
group = "plot"
order = 999
parts = ["Foo", "Bar"]
aliases = ["foobar", "Foo Bar", "某某复合写法"]
print = true                     # 需要 #FooBar 时写；省略则只输出 Foo / Bar
```

> `parts` 默认不输出自身，但可以用 `print = true` 强制输出组合名。
>
> 如果组合名不需要出现，省略 `print` 即可；需要单独分类时也可以改成 atomic + `parents`。

新增“保留分类关系、但不打印自身”的分类标签（必须有 `parents`）：

```toml
[AnthroDragon]
group = "species"
order = 2050
parents = ["Dragon"]
print = false                    # 输出 Dragon → Scalie → Furry，不输出 AnthroDragon
```

- `print = true` 或省略：默认输出自身（`parts` 除外）
- `print = false`：隐藏自身；父集 / parts 继续展开
- `print` 可用于所有标签；`parts` 省略时默认隐藏，写 `true` 可显示组合名
- 纯原子标签写 `print = false` 会输出空集合，确认这是想要的效果再写
- TOML 字段名是 `print`；Python 内部变量名用 `print_self`，避免遮蔽内置 `print`

别名与命名：

- 同一别名（normalize 后）全局只能属于一个规范名；
- 不要把规范名自己写进 `aliases`（会 WARN）；
- 简体、繁体、日文、空格写法分别列出；空字符串别名非法；
- 表名输出就是 hashtag，大小写会原样显示：除 `format` / `lang` 组（`#en` `#zh` `#txt` 用小写）外，一律 PascalCase（小写会 WARN）；
- `order` 建议留间隔（+10），方便以后插入。

## 6. 校验

校验在 `Vocabulary` 构造时完成（`load_vocabulary()` = 读文件 + 校验），**没有额外命令行工具**：
改完词表跑测试即可；仓库当前没有跑 pytest 的 CI，部署前本地跑。

```bash
pytest test/test_tags.py -q
```

`test/test_tags.py` 里的三类用例：

| 用例 | 作用 |
|---|---|
| 规则用例（归一 / 拆分 / 闭包 / 匹配 / 各条校验） | 锁住 `sources/tags.py` 的行为 |
| `test_shipped_vocabulary_has_no_errors` | 守门：`data/tags.toml` 与 `data.example/tags.toml` 加载后 `errors == []`，改坏就红 |
| `test_documented_examples` | 本文档里的解析示例回归，防止文档与词表漂移 |

`Vocabulary` 会检查，分两级：

**ERROR（阻断上线）**

- `schema` / `match` 取值非法
- 表名不合法，或 casefold 后与其他表名重复
- `parts` / `parents` / `aliases` 不是字符串数组；引用不存在、自指、`parts` 嵌套复合标签
- `parts` 与 `parents` 同时非空
- `parents` 指向复合标签
- `parts` / `parents` 成环
- `print` 不是布尔值
- 别名为空，或 normalize 后撞车
- `order` 不是整数、`group` 不是字符串

**WARN（需人工确认，不阻断）**

- 表名不是 PascalCase（`format` / `lang` 组除外）
- `meta.schema` 没写（按 `2` 处理）
- `aliases` 内部重复，或把规范名自己写进 `aliases`
- `name` 与 `parts` 拼接不一致（提醒确认该用复合还是原子 + parents）
- `group` 没列进 `meta.groups`（会排到最后）

怎么读校验结果：

```python
import logging

from sources.tags import load_vocabulary

logger = logging.getLogger(__name__)

vocab = load_vocabulary()            # 默认 data/tags.toml
if vocab.errors:                     # 结构性错误：按需阻断启动
	raise SystemExit("标签词表有误：" + "；".join(vocab.errors))
for warning in vocab.warnings:       # 命名风格 / 重复别名：打日志，不阻断
	logger.warning("标签词表：%s", warning)
```

有 ERROR 不应上线；WARN 需人工确认（多半是命名风格或重复别名）。

> 当前 `bot.py` 只调用 `install_tag_archive()` 装配留档，并不检查 `vocabulary.errors`；上面的 `SystemExit` 是推荐的启动校验写法。TOML 语法错误会被 `canonicalize_tags()` 捕获并降级为「保留原始写法」，只在日志里留 warning。

## 7. 运行时接入

**接线只有两处：启动装配一次 + 数据模型自带（不用改业务代码）。**

```python
# bot.py，run_polling 之前
from services.tag_service import install_tag_archive

install_tag_archive()      # 未识别写法 → data/unknown_tags.json（进程内装一次）

# sources/base.py（已实现，不用再改）
@dataclass
class Novel:
	tags: list[str] = field(default_factory=list)

	def __post_init__(self) -> None:
		self.tags = canonicalize_tags(self.tags)   # 来源写法 → 规范名（词表缺失时原样保留）
```

因为规范化和留档发生在**模型构造**时，下面这些都自动拿到规范标签，**不需要各自接线**：

| 位置 | 为什么自动生效 |
|---|---|
| txt 头部（`format_novel_text` / `format_series_text`） | 读 `novel.tags`，构造时已规范 |
| 私聊 / 下载预览文案（`Novel.__str__`） | 同上 |
| `files_cache.json` 里的 caption | 同上（下载时 `str(item)`） |
| 新来源、新服务、新 handler | 只要构造 `Novel/Series/Author` 就生效 |

要**限流展示**（`act` / `plot` 组太细）时再用 `display_tags()`：

```python
from sources.format import format_tags
from sources.tags import display_tags

format_tags(display_tags(novel.tags, limit=8))   # 排序 + 截断；未识别写法仍会带出
```

### 7.1 职责边界

| 入口 | 做什么 | 不做什么 |
|---|---|---|
| `Vocabulary.resolve()` | 纯解析：规范名 → 标签集合（按 `print` 决定自身是否输出） | 不写盘；未知名只返回空集合（打 debug） |
| `Vocabulary.resolve_all()` | 解析：来源写法 → 规范名 + residual；`record=True` 时把 residual 交给回调 | 不截断、不排序 |
| `canonicalize_tags()` | **数据入口**：规范化 + 交给回调；词表不可用时原样返回 | 不截断（txt 头部要全量） |
| `display_tags()` | **展示**：排序 + `limit` + 未识别写法原样带出 | 不自己记账（避免一次调用记两遍） |
| `set_unknown_recorder(fn)` | sources 留给上层的回调位（`None` = 不写盘） | 不 import storage |
| `services.tag_service` | 启动装配 + `unknown_tags()` / `forget_unknown_tags()` / `clear_unknown_tags()` | 不判断「什么算未识别」 |
| `storage.unknown_tags` | 持久化：`count` 累加、首末时间、显式 `prune()`、原子写 | 归一键由 `sources.tags.normalize()` 产生 |

一句话：**规范化是「构造数据」的副作用，不是「展示」的责任**——`Novel/Series/Author` 一构造就规范并留档；展示层只负责排序和截断。

接入时的几个决策：

- **只加载一次**：`get_vocabulary()`（内部 `lru_cache`，首次加载就把 errors / warnings 写进日志），别每篇作品重读 TOML；
- **留档不会自动淘汰**：`data/unknown_tags.json` 里 `unknown_tags()` 读、`forget_unknown_tags([...])` 按条销账、`clear_unknown_tags()` 全清、`store.prune()` 手动瘦身；
- **限制输出数量**：`act` / `plot` 组很细，一篇文可能命中十几个标签，展示时建议取前 6~8 个（`display_tags(..., limit=8)`）；
- **`print` 只控制自身**：`print = false` 只隐藏该标签自身，父集 / parts 照常展开；不会隐藏其他标签；
- **`print` 默认值按类型不同**：`parts` 省略时默认 `false`，其余默认 `true`；`print = true` 可让 `parts` 节点也输出组合名；
- **SFW 与 R18 互斥（已实现）**：`display_tags()` 返回前会丢掉与 `R18` / `R18G` 同时出现的 `SFW`（先互斥再截断），模型层 `canonicalize_tags()` 因此自动生效；`resolve_all()` 仍是纯解析，不做这条规则。词表里必须保留 `SFW` / `R18` / `R18G` 这三个规范名；
- 词表是数据，不随主仓库提交：改完在数据目录单独提交；`/sync` 脚本只 `git add -- ':(glob)*.json'`，**不会带上 `tags.toml`**。

## 8. 常见坑

- 运行时**不要**再维护一份别名 JSON；索引由 `Vocabulary` 建；
- **留档发生在 `canonicalize_tags()`**（模型构造时）；`display_tags()` 只是展示并透传 `record`，别在两处都记账；
- **`parts` 默认不输出自身**：需要显示组合名时写 `print = true`；不需要时省略即可；
- **`print = false` 只隐藏自身**：父集继续输出；被别的标签当 parent 时，该节点在整条父链里都是透明的；
- **纯原子标签写 `print = false` 会输出空集合**：这是合法的，但要确认确实希望这个标签完全不出现；
- **`parts` 引用 `print = false` 的标签时**：该标签自身不输出，但它的 parents 会继续继承；如果不想继承父集，请不要把它放进 `parts`，或改成 alias / atomic；
- **TOML 的 `print` 在 Python 内读作 `print_self`**：不要用 `print` 作变量名，避免遮蔽内置函数；
- **评级互斥靠规范名**：`SFW` 与 `R18` / `R18G` 互斥写在 `sources/tags.py` 的 `EXCLUSIVE_RATINGS` / `EXCLUDED_BY_EXCLUSIVE`；改词表时别把这三个名字改掉。若给 `R18G` 挂 `parents = ["R18"]`，`#R18G` 会同时带 `#R18`；当前生产词表没有挂，`CBT` 只出 `#R18G #CBT`；
- **词表缺失不能让抓取失败**：`canonicalize_tags()` 内部降级为原样返回；生产上由 `bot.py` 启动装配，测试由 `test/conftest.py` 固定成样例词表；
- 传自定义词表试规则时用 `display_tags(..., vocab=..., record=False)`：否则「生产词表不认识」的写法会被记进 `data/unknown_tags.json`；
- 运行时**不要**做 OpenCC 简繁转换；要覆盖的写法写进 `aliases`；
- 业务代码**不要**自己实现另一套 `parts` / `parents` 语义，以 `sources/tags.py` 为准；
- 依赖只有标准库 `tomllib`（Python 3.12），不需要装 extra；`sources/tags.py` 也**不 import storage**（留档走回调）；
- 最小可运行例子见 `data.example/tags.toml`（`parts` 会继续继承 parents：`ケモホモ` → `#Gay #Furry`，`CBT` → `#R18 #R18G #BDSM #CBT`，`兽化` → `#Furry #Transformation #Transfur`）；生产词表给 `Transformation` 设了 `print = false`，所以生产上 `兽化` 只出 `#Furry #Transfur`。
