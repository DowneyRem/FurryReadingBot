# 标签词表：使用说明

后续接入与日常维护，只需要 **`tags.toml` + `tagtool.py`**。其余脚本是迁移/审计用的一次性工具，运行时不要依赖。

## 1. 配合关系

| 文件 | 是否运行时需要 | 作用 |
|------|----------------|------|
| `tags.toml` | **是** | 唯一词表源文件 |
| `tagtool.py` | **是** | 加载、校验、解析的参考实现 |
| `tags.example.toml` | 否 | 小样例，试规则用 |
| `migrate_tags.py` | 否 | 历史迁移，勿再当主路径 |
| `parity_check.py` / `audit_*.py` | 否 | 迁移期对照与审计 |

## 2. 运行时怎么用

把 `tagtool.py` 放进可 import 的路径，启动时加载一次词表：

```python
import tomllib
from tagtool import Vocabulary

with open("../data/tags.toml", "rb") as f:
  data = tomllib.load(f)

vocab = Vocabulary(data)
if vocab.errors:
  # 有结构性错误，应拒绝启动或告警
  for e in vocab.errors:
    print("ERROR", e)
```

依赖：

- Python 3.11+：标准库 `tomllib`
- Python 3.10：`pip install tomli`（`tagtool.py` 已做兼容导入）

### 解析一批来源标签

```python
raws = ["ケモホモ", "R-18", "兽化", "完全未知"]
tokens, residual = vocab.resolve_all(raws)
# tokens: 规范名列表，已按 order 排序，可直接拼 hashtag
# residual: 未识别的原始串
```

### 单条查询

```python
names = vocab.resolve_one("Gay Furry")  # -> ["GayFurry"] 或拆分命中的多个名
if names:
    expanded = set()
    for n in names:
        expanded |= vocab.resolve(n)
```

### 行为摘要

- 输入：任意来源写法（可带 `#`、空格、简繁、大小写混用）
- 输出：原子规范名集合（复合标签只贡献其 `parts`）
- 未命中：进入 `residual`，由调用方决定丢弃或原样保留

## 3. 改词表的流程

1. 编辑 `tags.toml`（见《标签词表-编写与设计》）
2. 本地校验：

```bash
python tagtool.py tags.toml
```

无 `ERROR` 再提交。脚本会打印标签数、别名键数，以及内置示例的解析结果（对生产文件示例可能大量 residual，以 errors/warnings 为准）。

3. 需要试复杂输入时，可在自己的脚本里 `Vocabulary(...).resolve_all([...])`，或临时改 `tagtool.py` 底部的 `demos`。

## 4. 不要做的事

- 不要在运行时再维护一份 `usedtags.json` 别名表；索引由 `Vocabulary` 从 TOML 构建
- 不要在运行时对中文做 OpenCC 简繁转换；要覆盖的写法写进 `aliases`
- 不要让业务代码自己实现另一套 parts/parents 语义；以 `tagtool.Vocabulary` 为准，或与之保持同一规则

## 5. 嵌入项目时的建议

- 将 `tags.toml` 视为配置/数据，与代码同版本发布或独立版本号
- 启动失败条件：`len(vocab.errors) > 0`
- `warnings` 可打日志，不阻断
- 若需给其他语言用，可在构建期从同一 TOML 生成 JSON 索引；**源文件仍以 TOML 为准**

## 6. 快速自检命令

```bash
# 校验生产词表
python tagtool.py tags.toml

# 用小样例看拆分与上级闭包
python tagtool.py tags.example.toml
```

`tags.example.toml` 在 `parts_mode = "split"` 下的预期包括：

- `ケモホモ` → `#Gay #Furry`
- `兽化` → `#Furry #Transformation #Transfur`
- `CBT` → `#R18 #R18G #BDSM #CBT`
