---

## 0. 一句话

私聊发 **Pixiv / Linpx 小说 / 系列 / 作者链接** → 按**作者**做名单校验 → 回传 `txt` / `zip` → 可一键分享到频道；未收录的作者走「用户申请 → 中转频道 → 管理员核验」。

当前是「**按作者授权 + 人工审核**」模式：没有基于正文的自动识别（标签只用于分享分流），没有翻译。

| 域 | 功能 | 位置 | 状态 |
|---|---|---|---|
| 命令 | `/start` `/help` `/ping` `/sponsor` | `handlers/start.py` | ✅ `/help` 按身份裁剪 |

| 命令 | `/black` `/furry` 申请 | `handlers/author.py` | ✅ |
| 命令 | `/furryadd` `/blackadd` `/furryremove` `/blackremove` | `handlers/author.py` | ✅ 仅管理员 |
| 解析 | Linpx / FurryNovel 链接 | `sources/linpx/` | ✅ |
| 解析 | Pixiv 原站链接 | `sources/pixiv/` | ✅ R18 需登录态 |
| 抓取 | 单篇 / 系列 / 作者 | `sources/*/client.py` | ✅ |
| 生成 | 单篇 / 系列 / 作者的 txt、zip | `services/packaging.py` | ✅ 单章失败只跳过 |

| 申请 | 后果告知 + 二次确认 + 冷却 | `services/apply_service.py` | ✅ 同一作者 1 天 1 次 |
| 审核 | 通过 / 拒绝 → 名单 + 通知 | `services/review_service.py` | ✅ 仅管理员 |
| 下架 | 拉黑 + 删除历史分享 | `services/takedown_service.py` | ✅ 失败可重试 |
| 下载 | 缓存 / 格式选择 / 首章试读 | `services/download_service.py` | ✅ 上传后删本地文件 |
| 分享 | 三按钮 + 冷却 + 标签分流 | `services/share_service.py` | ✅ 正式分享同时发群组 |
| 存储 | 名单 / 申请 / 缓存 / 分享记录 | `storage/` | ✅ 本地文件 + 热加载 |
| 基础设施 | JSON / 文件 / AES zip / HTTP | `infra/`、`utils/` | ✅ |

补充说明：

- `/help` 先过 `transit_admin_policy`：非管理员只看到公开命令，管理员额外看到管理命令；判定失败按非管理员处理。
- Pixiv 正文清洗暂时关闭：`sources/pixiv/parse.py` 原样返回 `content`，正文标记会原样进 txt；`format_pixiv_content()` 保留但未接线。
- Pixiv 请求有多账号轮换与全局限流；`content_titles` 里 `available=false` 的章节跳过。
- 「📄 下载首章」复用 `dn`：`resolve_link(link, "novel")` 把系列链接换成首章，键盘 / handler 都不额外传数据。
- 管理员快捷命令不写申请记录、不占冷却；`/blackadd` 会同时移出兽人名单并下架历史分享，回执留在中转频道。
- 只有 txt 挂分享按钮；标签未命中 `#Furry` 时送中转频道，管理员 `cfy` 放行、`cfn` 删卡片。
- `JsonDict` 拼错字段静默返回 `None`（见 §2 P2）。

**测试现状**（2026-11-27）：`pytest test -q` → **614 passed / 8 skipped**；`pytest test -q --ignore=test/test_linpx.py` → **601 passed / 5 skipped**。跳过项是真实 API 用例（`LINPX_LIVE` / `PIXIV_LIVE`）与 3 条正文清洗用例。

## 4. 速查

### 环境变量

> 完整说明（默认值、生效条件、未使用变量、生产示例）见 [07 §4](07-配置与部署.md)，这里只列速查。

| 变量 | 必填 | 用途 |
|---|---|---|
| `BOT_TOKEN` | ✅ | Bot Token |
| `PIXIV_COOKIE` | ✅ | Pixiv 登录态 |
| `TEST_CHANNEL` | `test` 必填 | 测试频道；中转回退值 |
| `TRANSIT_CHANNEL` | 可选 | 审核 + 待确认分享 |
| `FURRY_READING` | `prod` 必填 | 兽人阅读频道 |
| `FURRY_NOVELS` | `prod` 必填 | 兽人小说频道 |
| `FURRY_READING_NEW_GROUP` / `TEST_GROUP` | 可选 | 分享同时发群组 |

- `PIXIV_COOKIE` 推荐裸 `PHPSESSID`，多个账号用换行或 `||` 分隔；登录态失效时 R18 内容会明确报错。
- 群组收到与频道相同的文件 / caption / 键盘，消息写入分享记录（下架一并删除）；Bot 需在群内且有发文件权限。
- `TRANSIT_CHANNEL` 未配置时复用 `TEST_CHANNEL`。

### 代码常量（`config.py`）

这些不是 `.env` 变量，改 `config.py` 后重新部署生效：

| 常量（数值见 `config.py`） | 用途 |
|---|---|
| `SHARE_MODE` | `test` 只发测试频道；`prod` 按评分分流 |
| `SHARE_SCORE_THRESHOLD` | 同时发兽人阅读的评分下限 |
| `CONCURRENT_UPDATES` | update 并发数（`1` = 串行） |
| `FETCH_CACHE_TTL_HOURS` | 请求缓存小时数 |
| `FILE_CACHE_TTL_DAYS` | `file_id` 缓存天数 |
| `SHARE_COOLDOWN_DAYS` | 分享冷却天数 |
| `SHARE_RECORD_TTL_DAYS` | 分享记录保留天数 |
| `BLACK_REQUEST_MATERIAL_TTL_MINUTES` | 提交截图的时限（分钟） |
| `APPLY_COOLDOWN_HOURS` | 申请冷却小时数（两类申请共用） |
| `FURRY_REQUEST_TTL_DAYS` | 兽人申请记录保留天数 |
| `BLACK_REQUEST_TTL_DAYS` | 下架申请记录保留天数 |

> 申请记录只淘汰已结束（通过 / 拒绝）的，待审核的不淘汰；`storage/` 不自带默认值，构造 Store 时现读 `config.py`。

### 命令

| 命令 | 作用 | 权限 |
|---|---|---|
| `/start` `/help` `/ping` | 欢迎 / 帮助 / chat_id 与语言 | 所有人 |
| `/sponsor` | 众筹 & 开源链接 | 所有人 |
| `/down <链接>` | 等价于发链接 | 所有人 |
| `/black [作者ID/链接]` | 作者申请下架 | 所有人 |
| `/furry [作者ID/链接]` | 申请兽人作者 | 所有人 |
| `/review` | 重推待审申请 | 仅管理员 |
| `/sync` | 推荐作者 + 运营数据同步 | 仅管理员 |
| `/furryadd [作者ID/链接]` | 直接加兽人作者 | 仅管理员 |
| `/blackadd [作者ID/链接]` | 直接拉黑 + 删历史分享 | 仅管理员 |
| `/furryremove [作者ID/链接]` | 移出兽人作者名单 | 仅管理员 |
| `/blackremove [作者ID/链接]` | 解除拉黑（先重试删除） | 仅管理员 |

> `/help` 会按身份裁剪：`/black`、`/furry` 等公开命令所有人可见，`/review` 起的管理命令只发给中转频道管理员。callback 动作对照见 **04 第 3.3 节**。
