---

## 0. 一句话

私聊发 **Linpx 小说 / 系列 / 作者链接** → 按**作者**做名单校验 → 回传 `txt` / `zip` → 可一键分享到频道；未收录的作者走「用户申请 → 中转频道 → 管理员核验」。

当前是「**按作者授权 + 人工审核**」模式：**没有**基于标签 / 正文的自动识别，**没有**翻译。

## 5. 速查

### 环境变量

> 完整说明（默认值、生效条件、未使用变量、生产示例）见 [07 §4](07-配置与部署.md)，这里只列速查。

| 变量 | 必填 | 默认 | 用途 |
|---|---|---|---|
| `BOT_TOKEN` | ✅ | — | 缺失直接退出 |
| `TEST_CHANNEL` | 分享必填 | 空 | `SHARE_MODE=test` 时的分享目标；也是中转频道回退值 |
| `TRANSIT_CHANNEL` | 可选 | `TEST_CHANNEL` | 中转频道：待审作者申请 + 标签未确认兽人小说的分享（未配置时复用 `TEST_CHANNEL`） |
| `FURRY_READING` | `prod` 必填 | 空 | 兽人阅读；评分达标时同时发这里 |
| `FURRY_NOVELS` | `prod` 必填 | 空 | 兽人小说；`prod` 模式下所有作品都发这里 |
| `FURRY_READING_NEW_GROUP` / `TEST_GROUP` | 可选 | 空 | 当前未使用 |

### 代码常量（`config.py`）

这些不是 `.env` 变量，改 `config.py` 后重新部署生效：

| 常量 | 值 | 用途 |
|---|---|---|
| `SHARE_MODE` | `prod` | `test` 只发 `TEST_CHANNEL`；`prod` 按评分分流到正式频道 |
| `SHARE_SCORE_THRESHOLD` | `6` | `prod` 下同时发兽人阅读的评分下限（按下载时写入缓存的评分判断） |
| `SHARE_COOLDOWN_DAYS` | `3` | 同一作品分享冷却天数 |
| `FILE_CACHE_TTL_DAYS` | `7` | `file_id` 缓存天数 |
| `CONCURRENT_UPDATES` | `8` | update 并发数，`1` = 串行（必须 ≥ 1） |
