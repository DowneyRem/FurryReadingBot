## 这是什么

一个 Telegram 上的**小说下载 / 分享 Bot**，只服务**兽人向（furry）小说**。

把 **Pixiv 原站**或 **Linpx** 的链接发给它，它会：
- 把**单篇**、**整个系列**，或**某位作者的全部作品**打包成 `txt` / `zip` 发给你；
- 收到 `txt` 后，你可以顺手把作品**分享到兽人小说频道**；
- 遇到还没收录的作者，会提示你**申请**；管理员核验通过后就能下载。


## 怎么用
**第 1 步 · 私聊 Bot，发一条链接**（一次一条）：

```text
https://linpx.ink/pixiv/novel/18012577     单篇
https://linpx.ink/pixiv/series/16181401    系列
https://linpx.ink/pixiv/user/130586197     作者的全部作品
```

Pixiv 原站链接同样能用，作品 ID 是同一套：

```text
https://www.pixiv.net/novel/show.php?id=18012577    单篇
https://www.pixiv.net/novel/series/16181401         系列
https://www.pixiv.net/users/130586197               作者的全部作品
```

> Pixiv 原站的 **R18 作品**需要部署方在 `.env` 里配置 `PIXIV_COOKIE`；该变量是**启动必填**（没配 Bot 起不来），登录态失效时会提示需要登录态，而不是给出空文件。

**第 2 步 · 点按钮，等文件**

| 按钮 | 什么时候有 |
|---|---|
| `📄 下载本章` | 发单篇链接时 |
| `📒 下载系列 txt` / `📚 下载系列 zip` | 发系列链接，或单篇属于某个系列时 |
| `👤 全部下载` | 发作者主页时（最慢，按系列逐个抓） |

**第 3 步 · 想分享就点一下**

收到 `txt` 后下方会出现 `🉑 公开分享`（署名）/ `㊙️ 私密分享`（匿名）/ `🈲 拒绝分享`。
同一篇作品在分享冷却期内只能分享一次（冷却时长见 `config.py` 的 `SHARE_COOLDOWN_DAYS`）；`zip` 没有分享按钮。
部署方配置群组后，正式分享会同时发到群组（文件与频道一致；私聊回执只列出频道）。

> **作者不在名单？** 点 `✅ 申请兽人作者`，读完说明点确认，等管理员核验。
> 
> **你是作者、想下架？** 发 `/black`，按提示提交 Pixiv 后台截图。

## 命令

| 命令 | 作用 |
|---|---|
| `/start` | 打招呼 |
| `/help` | 看命令列表 |
| `/ping` | 返回当前 chat_id |
| `/sponsor` | 众筹 & 代码开源链接 |
| `/down <链接>` | 和直接发链接一样 |
| `/furry [作者ID或主页链接]` | 申请收录某位兽人作者 |
| `/black [作者ID或主页链接]` | 作者本人申请下架 |
| `/review` | 管理员：把待审核的申请再推送一遍 |
| `/sync` | 管理员：把运营数据同步到私有仓库 |

完整场景、各种失败提示、管理员操作：**[02 · 用户使用流程](docs/02-用户使用流程.md)**。

## 常见问题

| 问题 | 回答 |
|---|---|
| 发了链接没反应？ | 确认是**私聊**、消息里只有**一个**链接、链接来自 Pixiv 或 Linpx |
| 为什么 Pixiv 的 R18 作品下不了？ | 原站 R18 只对登录用户开放，部署方在 `.env` 配好 `PIXIV_COOKIE`（启动必填）后才能读取 |
| 为什么提示「仅可下载兽人小说」？ | 该作者还不在名单里，点「✅ 申请兽人作者」等核验 |
| 为什么分享没出现在频道？ | 可能在冷却期、缓存过期，或该作者已被下架；提示里会写原因 |
| 为什么下载很慢？ | 系列 / 作者全量要逐章抓取，章节越多越慢 |
| 文件会一直留在服务器上吗？ | 不会，发送完成后立即删除 |
| 申请多久有结果？ | 人工核验，没有固定时间 |
| 能一次发多条链接吗？ | 不能，一次一条 |
| 群聊里能用吗？ | 只处理私聊；`/down` 在群里也能用，但不建议 |
