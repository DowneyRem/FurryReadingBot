## 🚀 快速开始
### ⤴️ 分享小说
> [!TIP] 
> 1. **私聊 Bot，发送一条** Pixiv 或 Linpx 链接（单篇 / 系列 / 作者主页）
> 2. **点击按钮**：`📄 下载本章` / `📒 下载系列 txt` / `📚 下载系列 zip` / `👤 全部下载`
> 3. **分享小说**：下载 `txt` 小说后，可选择 `🉑 公开分享`（署名）/ `㊙️ 私密分享`（匿名）/ `🈲 拒绝分享`


### 🐺 申请收录兽人作者
> [!TIP]
> 发送 **`作者主页链接`** 或 **`/furry 作者主页链接`** 后，点击 `✅ 申请兽人作者` 即可
>
> 管理员审核通过后，后续即可分享该作者的小说


### ©️ 版权投诉 / 申请下架
> [!NOTE]
> 发送 **`作者主页链接`** 或 **`/black 作者主页链接`** 后，点击 `🈲 申请下架`，提交 Pixiv 后台截图即可
>
> 管理员确认截图与申请作者一致后，Bot 将即刻删除历史分享并禁止后续分享


## 🤖 可用命令
| 命令 | 作用 |
|---|------|
| `/start` | 开始 |
| `/help` | 查看命令 |
| `/sponsor` | 众筹支持 & 代码开源地址 |
| `/down <链接>` | 下载小说（等同直接发送链接） |
| `/furry <作者ID或链接>` | 申请收录兽人作者 |
| `/black <作者ID或链接>` | 作者本人申请下架 |
